## Critical Discovery: Paperclip UI Requires Root-Level Files

Mythic's paperclip UI (Installed Services → Agent → file browser) shows files at the `/Mythic/` root level. It **cannot navigate into subdirectories**. This means:

- ALL config files MUST be at `/Mythic/` root (alongside Dockerfile, main.py)
- NEVER create subdirectories for configs (paperclip can't see them)
- The `NN_Type_Detail.ext` flat-file naming convention exists BECAUSE we can't use directories
- `CONFIG_DIR` must default to `/Mythic/`, NOT `/Mythic/configs/`
- `config.json` must NOT set `DOLOS_CONFIG` to a subdirectory
